# AI Implementation Readiness Checklist

- [ ] Approved product, plan, deployment and use case identified.
- [ ] Decision conditions documented.
- [ ] Required organizational approvals complete.
- [ ] Administrator/user roles defined.
- [ ] Access appropriately limited.
- [ ] Required security settings configured.
- [ ] Data-use/retention settings configured.
- [ ] Integrations and permissions understood.
- [ ] Out-of-scope uses communicated.
- [ ] Human review expectations documented.
- [ ] Users understand relevant limitations.
- [ ] Error/concern escalation route available.
- [ ] Incident reporting route available.
- [ ] Offboarding/export needs understood.
- [ ] Post-implementation review planned.
- [ ] Reassessment triggers documented.
